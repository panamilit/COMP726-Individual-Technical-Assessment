# COMP726 - Individual-Technical-Assessment


This repository contains practical work completed for the COMP726 at Auckland University of Technology (AUT).

It includes Python implementations of core blockchain concepts and Solidity
smart contracts deployed and tested on the Ethereum Sepolia network.

## Repository structure

- **Part_A** - blockchain hashing, chain validation, proof of work and ECDSA
  key generation in Python.
- **Part_B/AUT_Part_B** - the original Solidity contract and supporting
  materials prepared for the AUT technical assessment.
- **Part_B/Playground_Part_B** -  an extended Solidity playground for deploying
  a contract and experimenting with on-chain interactions on Sepolia.

The repository is intended for educational and portfolio purposes.
